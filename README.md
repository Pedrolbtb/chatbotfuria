# 🐾 Chatbot Fúria

Este é um projeto web criado com **Next.js** e **Tailwind CSS**, feito para a torcida da Fúria interagir através de um chatbot integrado com Landbot. Caso queira testar na deploy entre no link: https://chatbotfuria-4rhu.vercel.app/

## 🚀 Tecnologias usadas

## 💻 Requisitos

- Node.js (v18 ou superior recomendado)
- npm (v9 ou superior)
- Git (opcional)

---

## 🧩 Instalação

1. **Clone o repositório**:

```bash
git clone https://github.com/seu-usuario/chatbotfuria.git
cd chatbotfuria
```
2. **Instale as dependências
   
```bash
npm install
```
3. Execute o Projeto localmente

```bash
npm run dev
```
4. Acesse no navegador: http://localhost:3000
